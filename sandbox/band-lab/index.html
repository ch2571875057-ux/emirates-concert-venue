需要通过本地服务器打开

你是直接双击打开的 index.html，浏览器不允许 file:// 页面加载 ES 模块和 .glb 模型，所以这里只会白屏。

  1. 回到 sandbox\band-lab\，双击 打开乐队沙盒.bat（推荐，自动起服务器并开页面）。
  2. 或者手动：在本目录上级 concert1\ 里执行 python -m http.server 8152 --bind 127.0.0.1， 然后浏览器访问 http://127.0.0.1:8152/sandbox/band-lab/index.html。
  3. 只想看静态图：双击 打开预览图册.bat，那个不需要服务器。

如果已用 http 打开仍然白屏，请按 F12 打开控制台，把红色报错发我。
